How to get started

  1. Open the SQL guide and run its setup script in your MySQL database to create the tables and insert the sample rows.
  2. For each challenge, write and run a query in MySQL, then check the results.
  3. Paste your SQL query (not its result) into the challenge box and select Run Query to check your answer.
